# v1.0.0 reviewer release

Four notebooks provide a 100-cell known-orientation convergence comparison,
a paired 1,300-fit Figure 3 preview, a two-epoch training demonstration and
four specular-free experimental cases with unknown orientations. All inference
notebooks explicitly use the high-missingness released model and serial float64
CG with L2 loss, 10 one-to-one rounds plus 10 simulated-fractional rounds and
up to 500 optimizer iterations per round.

Root setup installs the AI package and GPL conventional GIDInd Python port,
registers a notebook kernel and verifies pinned public HF assets. Both original
checkpoints and the published frozen sampler remain unchanged. MCMC and the
opt-in batched backend remain available outside the notebooks. COD preparation
uses global three-decimal Niggli keys before splitting. Original GMM coordinate
mapping, test-data safeguards, angle-unit correction and identifiability checks
are retained.

## CPU validation

Validation environment: macOS ARM64, Python 3.13, PyTorch 2.14.1,
scikit-learn 1.9.0. The fixed 100-cell regression recovers **99/100**, exactly
matching all saved pre-change predictions and refined cells. The newly sampled
notebook cohort recovers **97/100** after refinement and **6/100** before it;
these are different cohorts and both use the unchanged strict 0.1 Å/0.1° criterion.

The full AI/port suite passed **282 tests**; **26 CUDA checks** were skipped
because no CUDA hardware is available. The actual serial optimizer matching
calls were checked as 10 one-to-one plus 10 simulated-fractional rounds.
The paired Figure 3 preview completed all **1,300 records**; 44 deliberately
underconstrained patterns had fewer than three reflections after peak removal
and remain unsuccessful entries in the denominator. No fit raised a runtime
exception. The convergence and robustness cohort arrays are identical.

Clean-clone setup with an empty asset cache and disabled HF credentials passed,
as did a repeat setup using verified local downloads. Built AI and port wheels
import outside the repository, including compatibility, COD and MCMC APIs.

All four default notebooks executed top-to-bottom, with inline SVG output and
PDF/SVG exports. The training checkpoint confirms **32 actual Adam updates**
for two epochs; the final forward-only SWA normalization refresh increments
Lightning’s bookkeeping counter but not Adam’s parameter-step counters.
Epoch curves exclude that refresh; all raw logs are retained. The additional
COD precision/notebook contract checks passed (six tests), as did the private
branch’s targeted compatibility and shell checks (17 tests).

## Experimental protocol differences

The common notebook protocol replaces earlier case-specific schedules and uses
the high-missingness model for every case. Earlier PQ/MAPbBr3 defaults used the
standard model and 10 simulated-fractional rounds of up to 50 optimizer steps;
Cu-BOD used five one-to-one plus five fractional rounds of up to 10 steps;
NAIB-S11 used 10 one-to-one rounds of up to 50 steps. Cutoffs and scaling are
preserved. These protocols are not interchangeable historical reproductions.

Ranking uses acceptance, fit loss and deterministic orientation order; no
literature reference selects a candidate. NAIB-S11's leading candidate matches
all observations but exceeds the unchanged 5 × 10⁻⁵ loss threshold. Its rejected
ranked results and peak overlay remain visible. Accepted equivalent orientations
are not a count of crystallographically distinct solutions.

## Limits

Physical CUDA execution is **unverified on this Mac**. Automatic CUDA selection
of batched refinement remains disabled pending hardware correctness/performance
validation. The conventional Python port is an explicitly adapted implementation;
original MATLAB executable equivalence is unverified. Historical tuning/evaluation
separation cannot be fully reconstructed, and the legacy validation partition is
developmental. The training demo does not reproduce historical checkpoint training.
